Getting Started with LegalMinds
  1. Upload a Document: Select a PDF, DOCX, or TXT legal document.
  2. Automatic Processing: The app extracts text and analyzes clauses, dates, amounts, and obligations.
  3. Review Key Findings: Navigate tabs for Summary, Important Clauses, Points to Review, and Dates & Amounts.
  4. Multilingual Support: Select English, Hindi, Kannada, Marathi, Tamil, or Telugu in the header dropdown to switch both local UI text and Gemini AI generated responses.
  5. Hands-Free Speech Input: Click the microphone icon on Q&A inputs to speak your question using browser-native Web Speech API without requiring any API key.
  6. Interactive Q&A: Ask questions grounded strictly in document context in the Ask Questions tab.
  7. Compare Agreements: Contrast two legal documents side-by-side using factual line diffs and Gemini AI comparison.
  8. Lawyer Consultation Prep: Generate a consultation guide or export a clean PDF report.
Operating Modes & Decision Logic

LegalMinds uses an intelligent decision router to maximize answer correctness while optimizing Gemini API token usage:

⚡ Auto (Smart Mode)
Automatically uses local Python processing for deterministic tasks (clause search, text diffs, date extraction) and Gemini AI for complex natural-language interpretation. Automatically falls back to offline analysis if Gemini is unavailable.
✨ Gemini AI
Explicitly requests Gemini AI for interpretation. If Gemini is unavailable or quota limit is reached, displays a clear notification badge without pretending the output came from AI.
🔒 Offline Mode
Strict guarantee of ZERO Gemini API calls. Uses local text extraction and local rule-based Q&A engines. Works completely without internet or API keys.
Status Indicators & Offline Banner
🟢 Gemini AI Active API key is active and Gemini AI interpretation is live.
🟠 Gemini Limit Reached Free-tier API quota limit reached. App automatically uses smart local retrieval.
🔴 Gemini Not Configured No API key provided. App operates seamlessly in local offline mode.
